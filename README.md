# EE3140-PA
Program source code for Programming assignments under EE3140.

The programs are written in ANSI C, and will compile under any standard C Compiler
like GCC/Clang. However to run and get the output (plot window/pdf/gif), you need to
have **gnuplot** installed in/on path.

```
sudo apt install gnuplot gcc # On debian based systems
sudo dnf install gnuplot gcc # On RHEL based systems
```
